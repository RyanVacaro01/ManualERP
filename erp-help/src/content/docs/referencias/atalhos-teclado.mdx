## Personalizados

### Criar Atalho Personalizado

1. Acesse **Extras → Configurações**
2. Vá em **Atalhos**
3. Clique em "Novo Atalho"
4. Configure:
   - Combinação de teclas
   - Ação
   - Módulo (se aplicável)
5. Salve

### Gerenciar Atalhos

| Ação | Descrição |
|------|-----------|
| Visualizar | Lista todos os atalhos |
| Editar | Alterar combinação |
| Desativar | Temporariamente desabilitar |
| Remover | Excluir atalho |

## Dicas

:::tip[Dica]
Pressione `?` em qualquer lugar para ver a lista completa de atalhos.
:::

:::tip[Dica]
Use `Ctrl + K` para busca rápida em qualquer módulo.
:::

:::tip[Dica]"
Memorize os atalhos mais usados para ganhar produtividade.
:::
