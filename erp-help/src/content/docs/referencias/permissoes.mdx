## Configurar Permissões

<Steps>

1. **Acesse o módulo**
   
   Clique em **Pessoas** no menu lateral.

2. **Selecione o funcionário**
   
   Clique no funcionário que deseja configurar.

3. **Acesse permissões**
   
   Clique na aba "Permissões".

4. **Configure cada módulo**
   
   Marque ou desmarque as permissões:
   - Visualizar
   - Criar
   - Editar
   - Excluir
   - Relatórios

5. **Salve**
   
   Clique em "Salvar Alterações"

</Steps>

## Perfis Personalizados

### Criar Perfil Customizado

1. Acesse **Pessoas → Perfis**
2. Clique em "Novo Perfil"
3. Defina o nome
4. Configure as permissões
5. Salve

## Logs de Permissão

Toda alteração de permissão é registrada:

| Campo | Descrição |
|-------|-----------|
| Data/Hora | Quando foi alterado |
| Usuário | Quem alterou |
| Funcionário | Quem teve a permissão alterada |
| Módulo | Qual módulo |
| Permissão | O que foi alterado |

## Boas Práticas

:::tip[Dica]
Princípio do menor privilegiamento: conceda apenas as permissões necessárias.
:::

:::tip[Dica]
Revise as permissões regularmente, especialmente quando alguém muda de cargo.
:::

:::caution[Importante]
Nunca compartilhe contas de usuário. Cada pessoa deve ter sua própria conta.
:::
