O módulo de Custos permite controlar e analisar todos os custos da operação.

## Funcionalidades

- Cálculo automático de custos
- Rateio de despesas
- Análise de margem de lucro
- Relatórios de custos
- Histórico de variações

## Tipos de Custos

### Custo de Produto

| Componente | Descrição |
|------------|-----------|
| Custo de Aquisição | Valor pago ao fornecedor |
| Frete de Entrada | Custo do frete na compra |
| ICMS | Imposto sobre a mercadoria |
| PIS/COFINS | Tributos federais |
| Outros Impostos | Diversos |

### Custo Fixo

- Aluguel
- Salários
- Encargos sociais
- Depreciação
- Energia elétrica

### Custo Variável

- Comissões
- Frete de entrega
- Embalagem
- Material de consumo

## Cálculo de Custo

<Steps>

1. **Acesse o módulo**
   
   Clique em **Custos** no menu lateral.

2. **Selecione o período**
   
   Escolha o mês/ano de referência.

3. **Importe dados**
   
   - Notas fiscais de entrada
   - Despesas fixas
   - Despesas variáveis

4. **Revise os valores**
   
   Verifique se todos os custos estão corretos.

5. **Gere o relatório**
   
   Clique em "Calcular Custos" para processar.

</Steps>

## Rateio de Despesas

O rateio distribui despesas fixas entre os produtos:

### Métodos Disponíveis

| Método | Descrição | Quando Usar |
|--------|-----------|-------------|
| Por Quantidade | Divide igualmente | Produtos similares |
| Por Peso | Baseado no peso | Logística |
| Por Volume | Baseado no tamanho | Armazenagem |
| Por Valor | Baseado no preço | Custos financeiros |

### Configurar Rateio

1. Acesse **Custos → Configurações**
2. Selecione o método de rateio
3. Configure as categorias
4. Salve as configurações

## Fórmulas Importantes

### Custo Total
```
Custo Total = Custo Aquisição + Frete + Impostos + Rateio Fixo + Rateio Variável
```

### Margem de Lucro
```
Margem (%) = ((Preço Venda - Custo Total) / Preço Venda) × 100
```

### Markup
```
Markup = Preço Venda / Custo Total
```
