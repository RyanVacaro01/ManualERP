O módulo de Produção permite gerenciar todo o processo de fabricação.

## Funcionalidades

- Ordens de produção
- Controle de matéria-prima
- Apontamento de produção
- Controle de qualidade
- Rastreabilidade

## Fluxo de Produção

```

│  Venda   │   │Produção  │   │  /       │   │Pronto    │

                     │              │
                     ▼              ▼
              ┌──────────┐   ┌──────────┐
              │Matéria-  │   │Controle  │
              │Prima     │   │Qualidade │
              └──────────┘   └──────────┘
```

## Tipos de Produção

| Tipo | Descrição | Exemplo |
|------|-----------|---------|
| **Encomenda** | Produz sob demanda | Produto personalizado |
| **Estoque** | Produz para estoque | Produto padronizado |
| **Continua** | Produção contínua | Linha de montagem |

## Criar Ordem de Produção

<Steps>

1. **Acesse o módulo**
   
   Clique em **Produção** no menu lateral.

2. **Clique em "Nova Ordem"**
   
   Botão no canto superior direito.

3. **Selecione o produto**
   
   - Busque o produto a ser produzido
   - Informe a quantidade
   - Defina a data prevista de conclusão

4. **Configure a ordem**
   
   - **Tipo** - Encomenda ou Estoque
   - **Prioridade** - Normal, Urgente
   - **Observações** - Instruções especiais

5. **Revise matéria-prima**
   
   O sistema lista os materiais necessários:
   - Verifique disponibilidade
   - Reserve estoque (se necessário)

6. **Confirme a ordem**
   
   Clique em "Criar Ordem de Produção"

</Steps>

## Ordem de Produção

### Dados da Ordem

| Campo | Descrição |
|-------|-----------|
| Número | Número único da ordem |
| Produto | Produto a ser fabricado |
| Quantidade | Qtd a produzir |
| Data Início | Quando começará |
| Data Fim | Previsão de conclusão |
| Status | Situação atual |

### Status da Ordem

| Status | Cor | Descrição |
|--------|-----|-----------|
| **Criada** | Cinza | Ordem criada |
| **Iniciada** | Azul | Produção em andamento |
| **Pausada** | Amarelo | Produção pausada |
| **Concluída** | Verde | Produção finalizada |
| **Cancelada** | Vermelho | Ordem cancelada |

## Matéria-Prima

### Controle de Materiais

A tela mostra todos os materiais necessários:

| Material | Quantidade Necessária | Disponível | Status |
|----------|----------------------|------------|--------|
| Tecido Algodão | 10 m | 15 m | ✅ |
| Linha | 5 rolos | 5 rolos | ✅ |
| Botões | 100 un | 80 un | ⚠️ |
| Etiquetas | 50 un | 50 un | ✅ |

### Reserva de Estoque

Quando a ordem é iniciada:
1. Sistema verifica disponibilidade
2. Reserva automaticamente os materiais
3. Baixa do estoque (se configurado)

## Apontamento de Produção

Registre o andamento da produção:

<Steps>

1. **Acesse a ordem**
   
   Clique na ordem em andamento.

2. **Clique em "Apontar Produção"**
   
   Registre o progresso.

3. **Informe os dados**
   
   - Quantidade produzida
   - Quantidade com defeito
   - Horas trabalhadas
   - Operador responsável

4. **Confirme o apontamento**
   
   O sistema atualiza o progresso da ordem.

</Steps>

## Controle de Qualidade

### Checklist de Qualidade

Após a conclusão, verifique a qualidade:

- [ ] Dimensões corretas
- [ ] Acabamento adequado
- [ ] Sem defeitos visuais
- [ ] Embalagem correta
- [ ] Etiquetagem correta

### Aprovação/Reprovação

1. Acesse a ordem concluída
2. Clique em "Controle de Qualidade"
3. Preencha o checklist
4. Aprove ou reprove
5. Registre ocorrências (se houver)

## Rastreabilidade

Cada produto pode ser rastreado:

| Informação | Descrição |
|------------|-----------|
| Lote | Número do lote de produção |
| Data Fabricação | Data de produção |
| Validade | Data de validade (se aplicável) |
| Operador | Quem produziu |
| Matéria-Prima | Lotes dos materiais |

## Dicas

:::tip[Dica]
Use a prioridade "Urgente" para ordens com prazo apertado. Elas aparecem destacadas na lista.
:::

:::caution[Importante]
Sempre verifique a disponibilidade de matéria-prima antes de iniciar a produção.
:::
