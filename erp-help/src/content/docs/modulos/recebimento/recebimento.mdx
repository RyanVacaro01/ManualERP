O módulo de Recebimento permite controlar a entrada de mercadorias na empresa.

## Funcionalidades

- Conferência de volumes
- Nota fiscal de entrada
- Controle de qualidade
- Baixa automática de estoque
- Registro de avarias

## Fluxo de Recebimento

```
┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐
│Chegada   │──▶│Conferência│─▶│ Aprovação│──▶│ Baixa    │
│Mercadoria│   │          │   │          │   │ Estoque  │
└──────────┘   └──────────┘   └──────────┘   └──────────┘
                     │              │              │
                     ▼              ▼              ▼
              ┌──────────┐   ┌──────────┐   ┌──────────┐
              │Volumes   │   │Controle  │   │Atualização│
              │          │   │Qualidade │   │          │
              └──────────┘   └──────────┘   └──────────┘
```

## Status de Recebimento

| Status | Cor | Descrição |
|--------|-----|-----------|
| **Aguardando** | Cinza | Aguardando chegada |
| **Conferindo** | Amarelo | Conferência em andamento |
| **Aprovado** | Verde | Recebimento aprovado |
| **Rejeitado** | Vermelho | Rejeitado por qualidade |
| **Parcial** | Laranja | Recebimento parcial |

## Receber Mercadoria

<Steps>

1. **Acesse o módulo**
   
   Clique em **Recebimento** no menu lateral.

2. **Selecione a compra**
   
   Clique na compra que chegou.

3. **Conferir volumes**
   
   - Verifique a quantidade de volumes
   - Confira a integridade das embalagens
   - Registre qualquer avaria

4. **Conferir itens**
   
   - Leia o código de barras ou confira manualmente
   - Verifique quantidades
   - Confira qualidade

5. **Registre divergências**
   
   Se houver diferença:
   - Itens faltantes
   - Itens avariados
   - Itens diferentes

6. **Confirme o recebimento**
   
   Clique em "Confirmar Recebimento"

</Steps>

## Conferência de Itens

### Checklist

- [ ] Quantidade conferida
- [ ] Itens conferidos um a um
- [ ] Qualidade verificada
- [ ] Embalagem íntegra
- [ ] Nota fiscal conferida
- [ ] Etiquetas corretas

### Registro de Divergência

| Tipo | Descrição | Ação |
|------|-----------|------|
| **Falta** | Item não veio | Notificar fornecedor |
| **Sobra** | Item a mais | Devolver ou negociar |
| **Avaria** | Produto danificado | Registrar e notificar |
| **Troca** | Item errado | Devolver e solicitar correto |

## Nota Fiscal de Entrada

### Dados da NF-e

| Campo | Descrição |
|-------|-----------|
| Número | Número da NF-e |
| Série | Série da NF-e |
| Data Emissão | Data de emissão |
| Valor Total | Valor da nota |
| Fornecedor | Emitente |

### Validação Automática

O sistema valida automaticamente:
- ✅ CNPJ/CPF do emitente
- ✅ Chave de acesso
- ✅ Valores dos impostos
- ✅ Itens descritos

## Controle de Qualidade

### Critérios de Análise

| Critério | Descrição | Peso |
|----------|-----------|------|
| Dimensões | Tamanho correto | 30% |
| Acabamento | Qualidade visual | 30% |
| Funcionalidade | Funciona corretamente | 25% |
| Embalagem | Embalagem adequada | 15% |

### Aprovação/Rejeição

1. Selecione o item
2. Avalie cada critério
3. Aprove ou reprove
4. Registre observações
5. Confirme

## Baixa de Estoque

Após a aprovação, o estoque é atualizado automaticamente:

- Quantidade aumentada
- Custo médio recalculado
- Lote registrado
- Data de validade (se aplicável)

## Dicas

:::tip[Dica]
Use leitura de código de barras para agilizar a conferência.
:::

:::caution[Importante]
Sempre registre avarias imediatamente para garantir a reclamação ao fornecedor.
:::
