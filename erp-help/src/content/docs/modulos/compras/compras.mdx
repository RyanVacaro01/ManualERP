O módulo de Compras permite gerenciar todo o processo de compras da empresa.

## Funcionalidades

- Cotação com fornecedores
- Pedidos de compra
- Aprovação de compras
- Recebimento de mercadorias
- Controle de fornecedores

## Fluxo de Compras

```
┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐
│ Necessidade│─▶│ Cotação  │─▶│ Aprovação│─▶│  Pedido  │
│  /        │   │          │   │          │   │ Compra   │
└──────────┘   └──────────┘   └──────────┘   └──────────┘
                     │              │              │
                     ▼              ▼              ▼
              ┌──────────┐   ┌──────────┐   ┌──────────┐
              │Fornecedores│ │ Validação│   │Recebiment│
              │          │   │          │   │          │
              └──────────┘   └──────────┘   └──────────┘
```

## Status da Compra

| Status | Cor | Descrição |
|--------|-----|-----------|
| **Rascunho** | Cinza | Compra em criação |
| **Cotação** | Amarelo | Aguardando cotações |
| **Aprovado** | Verde | Compra aprovada |
| **Enviado** | Azul | Pedido enviado ao fornecedor |
| **Recebido** | Verde | Mercadoria recebida |
| **Cancelado** | Vermelho | Compra cancelada |

## Criar Pedido de Compra

<Steps>

1. **Acesse o módulo**
   
   Clique em **Compras** no menu lateral.

2. **Clique em "Nova Compra"**
   
   Botão no canto superior direito.

3. **Selecione o fornecedor**
   
   - Busque por nome ou CNPJ
   - Selecione o fornecedor

4. **Adicione itens**
   
   - Busque o produto
   - Informe a quantidade
   - Defina o preço de compra

5. **Configure a compra**
   
   - **Data de entrega** desejada
   - **Condição de pagamento**
   - **Observações**

6. **Envie para aprovação**
   
   Clique em "Enviar para Aprovação"

</Steps>

## Cotação

### Solicitar Cotação

1. Acesse **Compras → Cotações**
2. Clique em "Nova Cotação"
3. Selecione os produtos
4. Escolha os fornecedores
5. Envie a solicitação

### Formulário de Cotação

| Campo | Descrição |
|-------|-----------|
| Fornecedor | Quem cotou |
| Produto | Item cotado |
| Preço Unitário | Valor proposto |
| Prazo de Entrega | Dias para entrega |
| Validade | Validade da proposta |

### Comparar Cotações

O sistema compara automaticamente:

| Fornecedor | Produto | Preço | Prazo | Total |
|------------|---------|-------|-------|-------|
| Fornecedor A | Widget | R$ 10 | 5 dias | R$ 1.000 |
| Fornecedor B | Widget | R$ 12 | 3 dias | R$ 1.200 |
| Fornecedor C | Widget | R$ 9 | 7 dias | R$ 900 |

## Aprovação de Compras

### Regras de Aprovação

| Valor da Compra | Aprovação Necessária |
|-----------------|---------------------|
| Até R$ 2.000 | Automática |
| R$ 2.000 - R$ 10.000 | Gerente |
| R$ 10.000 - R$ 50.000 | Diretor |
| Acima de R$ 50.000 | Diretoria |

### Processo de Aprovação

1. Acesse **Compras → Pendentes**
2. Clique na compra
3. Revise itens e valores
4. Aprove ou rejeite
5. Adicione observação

## Fornecedores

### Cadastro de Fornecedor

1. Acesse **Compras → Fornecedores**
2. Clique em "Novo Fornecedor"
3. Preencha os dados:
   - Razão social
   - CNPJ
   - Endereço
   - Contato
   - Dados bancários
4. Salve

### Classificação de Fornecedores

| Classificação | Critério |
|---------------|----------|
| **A** | Entrega pontual, qualidade |
| **B** | Bom desempenho geral |
| **C** | Problemas ocasionais |
| **D** | Problemas frequentes |

## Dicas

:::tip[Dica]
Use a cotação para comparar preços e escolher a melhor opção.
:::

:::caution[Importante]
Verifique o histórico do fornecedor antes de aprovar uma compra.
:::
