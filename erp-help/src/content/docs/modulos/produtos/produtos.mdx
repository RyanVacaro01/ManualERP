## Tela Principal

A tela de listagem mostra todos os produtos cadastrados com opções de:

- **Busca** - Por nome, SKU ou código de barras
- **Filtros** - Por categoria, status, fornecedor
- **Ordenação** - Por nome, preço, data de cadastro
- **Visualização** - Lista ou grade (cards)

### Colunas da Tabela

| Coluna | Descrição |
|--------|-----------|
| Imagem | Foto do produto |
| Nome | Nome do produto |
| SKU | Código único do produto |
| Preço | Preço de venda |
| Estoque | Quantidade disponível |
| Status | Ativo/Inativo |

## Cadastro de Produto

<Steps>

1. **Acesse o módulo**
   
   Clique em **Produtos** no menu lateral.

2. **Clique em "Novo Produto"**
   
   Botão localizado no canto superior direito.

3. **Preencha os dados básicos**
   
   - **Nome** (obrigatório) - Nome do produto
   - **SKU** (obrigatório) - Código único
   - **Descrição** - Descrição detalhada
   - **Categoria** - Selecione a categoria

4. **Configure preços**
   
   - **Preço de custo** - Quanto custa
   - **Preço de venda** - Quanto será vendido
   - **Margem** - Calculada automaticamente

5. **Adicione imagens**
   
   - Clique em "Adicionar Imagem"
   - Selecione o arquivo (JPG, PNG, WebP)
   - Arraste para reordenar

6. **Configure estoque**
   
   - **Quantidade atual** - Estoque disponível
   - **Ponto de reposição** - Limite para alerta
   - **Unidade** - kg, un, lt, etc.

7. **Salve o produto**
   
   Clique em "Salvar" para concluir o cadastro.

</Steps>

## Campos do Produto

### Dados Básicos

| Campo | Obrigatório | Descrição |
|-------|-------------|-----------|
| Nome | ✅ | Nome do produto |
| SKU | ✅ | Código único (auto-gerado se vazio) |
| Descrição | ❌ | Descrição detalhada |
| Categoria | ✅ | Categoria do produto |
| Marca | ❌ | Marca do produto |
| NCM | ❌ | Nomenclatura Comum do Mercosul |

### Preços

| Campo | Descrição |
|-------|-----------|
| Preço de Custo | Valor pago ao fornecedor |
| Preço de Venda | Valor cobrado do cliente |
| Preço Promocional | Valor em promoção |
| Margem de Lucro | Calculada automaticamente |

### Estoque

| Campo | Descrição |
|-------|-----------|
| Quantidade | Estoque disponível |
| Reservado | Quantidade em pedidos |
| Disponível | Quantidade - Reservado |
| Ponto de Reposição | Limite para alerta |

### Imagens

- **Formatos aceitos:** JPG, PNG, WebP
- **Tamanho máximo:** 5 MB por imagem
- **Resolução recomendada:** 1000x1000px
- **Máximo de imagens:** 10 por produto

## Ações Rápidas

Na listagem, cada produto possui ações rápidas:

| Ícone | Ação | Descrição |
|-------|------|-----------|
| ✏️ | Editar | Abrir formulário de edição |
| 👁️ | Visualizar | Ver detalhes do produto |
| 📋 | Duplicar | Criar cópia do produto |
| 🗑️ | Excluir | Remover o produto |
| 📦 | Estoque | Ajustar estoque rápido |

## Categorias

### Criar Categoria

1. Acesse **Produtos → Categorias**
2. Clique em "Nova Categoria"
3. Preencha:
   - Nome da categoria
   - Categoria pai (opcional)
   - Descrição
   - Ícone/Imagem
4. Salve

### Estrutura de Categorias

```
📦 Produtos
├── 👕 Roupas
│   ├── Camisas
│   ├── Calças
│   └── Vestidos
├── 👟 Calçados
│   ├── Tênis
│   ├── Sandálias
│   └── Botas
└── 🎒 Acessórios
    ├── Bolsas
    ├── Bonés
    └── Cintos
```

## Dicas

:::tip[Dica]
Use o SKU automático para evitar duplicidade. O sistema gera um código único baseado na categoria e data.
:::

:::caution[Importante]
Antes de excluir um produto, verifique se há estoque ou pedidos vinculados.
:::
