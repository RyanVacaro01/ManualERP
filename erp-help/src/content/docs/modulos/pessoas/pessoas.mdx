O módulo de Pessoas permite gerenciar funcionários, equipes e permissões de acesso.

## Funcionalidades

- Cadastro de funcionários
- Gestão de equipes
- Controle de permissões
- Histórico de acessos
- Relatórios de pessoas

## Tela Principal

A tela mostra todos os funcionários cadastrados:

| Coluna | Descrição |
|--------|-----------|
| Foto | Imagem do funcionário |
| Nome | Nome completo |
| Cargo | Função exercida |
| Departamento | Setor de lotação |
| Status | Ativo/Inativo |

## Cadastro de Funcionário

<Steps>

1. **Acesse o módulo**
   
   Clique em **Pessoas** no menu lateral.

2. **Clique em "Novo Funcionário"**
   
   Botão no canto superior direito.

3. **Preencha dados pessoais**
   
   - Nome completo
   - CPF
   - RG
   - Data de nascimento
   - E-mail
   - Telefone

4. **Preencha dados profissionais**
   
   - Cargo
   - Departamento
   - Data de admissão
   - Salário
   - Matrícula

5. **Configure acesso ao sistema**
   
   - Usuário
   - Senha temporária
   - Perfil de acesso

6. **Salve o funcionário**
   
   Clique em "Salvar"

</Steps>

## Equipes

### Criar Equipe

1. Acesse **Pessoas → Equipes**
2. Clique em "Nova Equipe"
3. Preencha:
   - Nome da equipe
   - Responsável
   - Descrição
4. Adicione membros
5. Salve

## Permissões

### Perfis de Acesso

| Perfil | Descrição | Acesso |
|--------|-----------|--------|
| **Admin** | Administrador total | Tudo |
| **Gerente** | Gestor de departamento | Depto + relatórios |
| **Operador** | Executa tarefas | Módulos específicos |
| **Consulta** | Apenas visualiza | Leitura apenas |

### Configurar Permissões

1. Acesse **Pessoas → Permissões**
2. Selecione o perfil
3. Configure para cada módulo:
   - 🔍 Visualizar
   - ✏️ Criar/Editar
   - 🗑️ Excluir
   - 📊 Relatórios
4. Salve
