O módulo de Clientes permite gerenciar todo o cadastro de clientes da empresa.

## Funcionalidades

- Cadastro completo de clientes
- Histórico de compras
- Limites de crédito
- Classificação (ativo, inativo, devedor)
- Documentos anexos

## Tela Principal

A tela de listagem mostra todos os clientes com:

- **Busca** - Por nome, CPF/CNPJ, e-mail
- **Filtros** - Por status, tipo, cidade
- **Ordenação** - Por nome, data de cadastro
- **Ações** - Editar, excluir, historico

### Colunas da Tabela

| Coluna | Descrição |
|--------|-----------|
| Nome | Razão social ou nome |
| CPF/CNPJ | Documento fiscal |
| E-mail | E-mail de contato |
| Telefone | Telefone principal |
| Cidade | Cidade do cliente |
| Status | Ativo/Inativo |

## Cadastro de Cliente

<Steps>

1. **Acesse o módulo**
   
   Clique em **Clientes** no menu lateral.

2. **Clique em "Novo Cliente"**
   
   Botão no canto superior direito.

3. **Selecione o tipo**
   
   - **Pessoa Física** - CPF
   - **Pessoa Jurídica** - CNPJ

4. **Preencha os dados pessoais**
   
   - Nome completo / Razão social
   - CPF / CNPJ
   - E-mail
   - Telefone
   - Data de nascimento (PF)

5. **Preencha o endereço**
   
   - CEP (preenchimento automático)
   - Logradouro
   - Número
   - Complemento
   - Bairro
   - Cidade
   - Estado

6. **Configure informações adicionais**
   
   - Limite de crédito
   - Condição de pagamento
   - Vendedor responsável
   - Observações

7. **Salve o cliente**
   
   Clique em "Salvar" para concluir.

</Steps>

## Campos do Cliente

### Dados Cadastrais

| Campo | Obrigatório | Descrição |
|-------|-------------|-----------|
| Nome | ✅ | Nome completo ou razão social |
| CPF/CNPJ | ✅ | Documento (validação automática) |
| E-mail | ✅ | E-mail principal |
| Telefone | ❌ | Telefone de contato |
| Tipo | ✅ | Pessoa Física ou Jurídica |

### Endereço

| Campo | Obrigatório | Descrição |
|-------|-------------|-----------|
| CEP | ✅ | Preenche endereço automaticamente |
| Logradouro | ✅ | Rua, avenida, etc. |
| Número | ✅ | Número do endereço |
| Complemento | ❌ | Sala, andar, etc. |
| Bairro | ✅ | Bairro |
| Cidade | ✅ | Cidade |
| Estado | ✅ | UF |

### Informações Comerciais

| Campo | Descrição |
|-------|-----------|
| Limite de Crédito | Valor máximo de crédito |
| Saldo Devedor | Valor em aberto |
| Condição de Pagamento | Prazo de pagamento |
| Vendedor | Vendedor responsável |
| Classificação | A, B, C, D |

## Classificação de Clientes

| Classificação | Critério | Ação |
|---------------|----------|------|
| **A** | Compras frequentes, em dia | Prioridade máxima |
| **B** | Compras regulares | Atenção normal |
| **C** | Poucas compras | Estimular compras |
| **D** | Inadimplentes | Bloquear vendas |

## Histórico de Compras

Acesse o histórico completo do cliente:

1. Clique no cliente desejado
2. Acesse a aba "Histórico"
3. Visualize:
   - Todos os pedidos
   - Valor total gasto
   - Frequência de compras
   - Última compra

## Ações Rápidas

| Ícone | Ação | Descrição |
|-------|------|-----------|
| ✏️ | Editar | Dados cadastrais |
| 📞 | Contato | Ligações e e-mails |
| 📋 | Pedidos | Lista de pedidos |
| 💰 | Financeiro | Contas a receber |
| 📄 | Documentos | Notas fiscais |

## Dicas

:::tip[Dica]
Use o CEP para preenchimento automático do endereço. Isso evita erros de digitação.
:::

:::caution[Importante]
Antes de excluir um cliente, verifique se há pedidos ou pendências financeiras.
:::
