O módulo de Extras reúne configurações avançadas e utilitários do sistema.

## Funcionalidades

- Configurações do sistema
- Integrações
- Logs de auditoria
- Backup e restauração
- Utilitários

| Configuração | Descrição |
|--------------|-----------|
| Geral | Dados da empresa, fuso horário |

| Utilitário | Descrição |

### 📋 Logs

| Log | Descrição |
|-----|-----------|

## Configurações Gerais

<Steps>

1. **Acesse o módulo**
   
   Clique em **Extras** no menu lateral.

2. **Acesse Configurações**
   
   Clique em "Configurações Gerais".

3. **Configure os dados**
   
   - **Razão Social** - Nome da empresa
   - **CNPJ** - Documento da empresa
   - **Endereço** - Endereço completo
   - **Telefone** - Telefone principal
   - **E-mail** - E-mail de contato

4. **Configurações do Sistema**
   
   - **Fuso Horário** - Horário de referência
   - **Idioma** - Idioma padrão
   - **Moeda** - Moeda do sistema
   - **Formato Data** - DD/MM/AAAA

5. **Salve as alterações**
   
   Clique em "Salvar" para aplicar.

</Steps>

## Notificações

### Tipos de Notificação

| Tipo | Canal | Descrição |
|------|-------|-----------|
| **E-mail** | E-mail | Envia e-mail automático |
| **Sistema** | Popup | Alerta no sistema |

## Logs de Auditoria

### Visualizar Logs

1. Acesse **Extras → Logs**
2. Filtre por:
   - Período
   - Usuário
   - Tipo de ação
   - Módulo
3. Consulte os registros

### Informações do Log

| Campo | Descrição |
|-------|-----------|
| Data/Hora | Quando aconteceu |
| Usuário | Quem realizou |
| Ação | O que foi feito |
| Módulo | Onde aconteceu |
| Detalhes | Informações extras |
| IP | Endereço de rede |

### Exemplo de Log

```
[01/08/2026 14:30:25] João Silva - Criar Pedido #1234
Módulo: Pedidos
IP: 192.168.1.100
Detalhes: Cliente: Maria Santos | Total: R$ 1.234,00
```

## Backup

### Criar Backup

1. Acesse **Extras → Backup**
2. Clique em "Criar Backup"
3. Selecione o que incluir:
   - ✅ Dados
   - ✅ Configurações
   - ☐ Arquivos (opcional)
4. Aguarde a conclusão
5. Baixe o arquivo

### Restaurar Backup

:::caution[Atenção]
A restauração sobrescreve os dados atuais. Faça backup antes!
:::

1. Acesse **Extras → Backup**
2. Clique em "Restaurar"
3. Selecione o arquivo de backup
4. Confirme a restauração
5. Aguarde a conclusão

### Backup Automático

Configure backup automático:

| Frequência | Recomendado |
|------------|-------------|
| **Diário** | Dados transacionais |
| **Semanal** | Configurações |
| **Mensal** | Backup completo |

## Utilitários

### Limpar Cache

Limpa cache do sistema para resolver problemas:

1. Acesse **Extras → Utilitários**
2. Clique em "Limpar Cache"
3. Confirme
4. Aguarde a conclusão

### Recalcular Estoque

Recalcula todos os saldos de estoque:

1. Acesse **Extras → Utilitários**
2. Clique em "Recalcular Estoque"
3. Confirme
4. Aguarde a conclusão

### Reindexar Busca

Atualiza o índice de busca:

1. Acesse **Extras → Utilitários**
2. Clique em "Reindexar"
3. Aguarde a conclusão

## Dicas

:::tip[Dica]
Configure backups automáticos para evitar perda de dados.
:::

:::caution[Importante]
Sempre faça backup antes de restaurar ou fazer grandes alterações.
:::
