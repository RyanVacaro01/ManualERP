Este guia apresenta o fluxo completo para criar um novo pedido de venda.

## Pré-requisitos

- ✅ Cliente cadastrado no sistema
- ✅ Produtos cadastrados com estoque
- ✅ Permissão para criar pedidos

## Fluxo Completo

<Steps>

1. **Acessar o módulo**
   
   - Clique em **Pedidos** no menu lateral
   - Clique em **"Novo Pedido"**

2. **Selecionar o cliente**
   
   - Busque por nome, CPF/CNPJ
   - Selecione o cliente
   - Verifique:
     - Limite de crédito disponível
     - Endereço de entrega
     - Condição de pagamento

3. **Adicionar produtos**
   
   Para cada produto:
   - Busque por nome ou SKU
   - Informe a quantidade
   - Confirme o preço unitário
   - Verifique se há estoque

4. **Configurar o pedido**
   
   | Campo | Descrição |
   |-------|-----------|
   | Data de Entrega | Quando o cliente deseja receber |
   | Condição de Pagamento | Prazo de pagamento |
   | Desconto | Desconto total (se aplicável) |
   | Frete | Valor do frete |
   | Observações | Instruções especiais |

5. **Revisar o pedido**
   
   Verifique:
   - Todos os itens estão corretos
   - Quantidades estão corretas
   - Preços estão corretos
   - Total está correto
   - Desconto aplicado corretamente

6. **Salvar ou enviar**
   
   - **Salvar como Rascunho** - Para revisar depois
   - **Enviar para Aprovação** - Envia para aprovação

</Steps>

## Valores do Pedido

### Resumo Financeiro

| Campo | Descrição |
|-------|-----------|
| Subtotal | Soma dos itens |
| Desconto | Desconto total |
| Frete | Valor do frete |
| **Total** | **Valor final** |

### Exemplo de Pedido

```
┌─────────────────────────────────────────────────────┐
│  Pedido #1234 - Cliente: Maria Santos              │
├─────────────────────────────────────────────────────┤
│  Item          Qtd    Preço    Total                │
│  Widget A       2    R$ 50   R$ 100                │
│  Widget B       1    R$ 80   R$  80                │
│  Widget C       3    R$ 30   R$  90                │
├─────────────────────────────────────────────────────┤
│  Subtotal:                    R$ 270               │
│  Desconto (10%):             -R$  27               │
│  Frete:                       R$  15               │
│  ─────────────────────────────────────             │
│  TOTAL:                       R$ 258               │
└─────────────────────────────────────────────────────┘
```

## Status do Pedido

Após salvar, o pedido passa pelos status:

1. **Rascunho** - Salvo para revisar
2. **Pendente** - Enviado para aprovação
3. **Aprovado** - Aprovado para processamento
4. **Separando** - Separação em andamento
5. **Faturado** - NF emitida
6. **Enviado** - Em transporte
7. **Entregue** - Cliente recebeu

## Regras de Aprovação

| Valor | Aprovação |
|-------|-----------|
| Até R$ 5.000 | Automática |
| R$ 5.000 - R$ 20.000 | Gerente |
| Acima de R$ 20.000 | Diretor |

## Erros Comuns

| Erro | Causa | Solução |
|------|-------|---------|
| Estoque insuficiente | Quantidade > disponível | Reduza quantidade ou aguarde estoque |
| Limite excedido | Crédito do cliente | Verifique com financeiro |
| Cliente bloqueado | Inadimplência | Regularize situação |
| Preço incorreto | Preço desatualizado | Atualize o preço do produto |

## Dicas

:::tip[Dica]
Use o atalho Ctrl+N para criar um novo pedido rapidamente.
:::

:::tip[Dica]
Salve como rascunho se precisar consultar algo antes de finalizar.
:::

:::caution[Importante]
Sempre verifique o limite de crédito do cliente antes de aprovar.
:::
