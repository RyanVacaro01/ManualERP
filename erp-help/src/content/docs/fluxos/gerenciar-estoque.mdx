## Consultar Estoque

### Busca Simples

1. Acesse **Estoque**
2. Use a barra de busca
3. Filtre por categoria, fornecedor

### Busca Avançada

| Filtro | Descrição |
|--------|-----------|
| Produto | Nome ou SKU |
| Categoria | Categoria do produto |
| Fornecedor | Fornecedor |
| Lote | Número do lote |
| Validade | Data de validade |
| Localização | Prateleira/endereço |

### Informações do Produto

| Campo | Descrição |
|-------|-----------|
| SKU | Código do produto |
| Produto | Nome do produto |
| Quantidade | Estoque atual |
| Reservado | Em pedidos pendentes |
| Disponível | Quantidade - Reservado |
| Custo Médio | Custo médio ponderado |
| Valor Total | Qtd × Custo Médio |

## Ajustes de Estoque

### Tipos de Ajuste

| Tipo | Quando Usar |
|------|-------------|
| **Conferência** | Após inventário físico |
| **Avaria** | Produto danificado |
| **Perda** | Produto perdido |
| **Sobra** | Produto encontrado |
| **Correção** | Erro de digitação |

### Realizar Ajuste

<Steps>

1. **Acesse o produto**
   
   Busque o produto no estoque.

2. **Clique em "Ajustar Estoque"**
   
   Botão nas ações do produto.

3. **Selecione o tipo de ajuste**
   
   - Entrada ou Saída
   - Motivo do ajuste

4. **Informe a quantidade**
   
   - Quantidade a ajustar
   - Justificativa

5. **Confirme o ajuste**
   
   Clique em "Confirmar"

</Steps>

## Inventário

### Criar Inventário

1. Acesse **Estoque → Inventário**
2. Clique em "Novo Inventário"
3. Configure:
   - Período
   - Produtos (todos ou selecionados)
   - Responsáveis
4. Inicie o inventário

### Processo de Contagem

1. Imprima a listagem de contagem
2. Contagem física dos produtos
3. Registre as quantidades
4. Compare com o sistema
5. Ajuste divergências
6. Finalize o inventário

### Relatório de Inventário

| Coluna | Descrição |
|--------|-----------|
| Produto | Nome do produto |
| Sistema | Quantidade no sistema |
| Contagem | Quantidade contada |
| Diferença | Variação |
| Ação | Ajustar ou ignorar |

## Lotes e Validade

### Gestão por Lote

| Campo | Descrição |
|-------|-----------|
| Lote | Número do lote |
| Fornecedor | Quem forneceu |
| Data Fabricação | Data de fabricação |
| Data Validade | Prazo de validade |
| Quantidade | Qtd no lote |

### PEPS (Primeiro a Entrar, Primeiro a Saída)

O sistema utiliza PEPS por padrão:
- Vendas usam o lote mais antigo
- Garante saída antes do vencimento
- Rastreabilidade completa

## Alertas de Estoque

### Configurar Alertas

| Alerta | Condição | Ação |
|--------|----------|------|
| **Estoque Baixo** | Abaixo do mínimo | Notificar Compras |
| **Estoque Crítico** | Abaixo do crítico | Urgência |
| **Validade Próxima** | 30 dias para vencer | Atenção |
| **Sem Movimento** | 90 dias sem saída | Revisar |
