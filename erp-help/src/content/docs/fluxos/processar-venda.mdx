Este guia apresenta o fluxo completo de processamento de uma venda, do pedido à entrega.


## Etapas do Processo

### 1. Criação do Pedido

- [ ] Selecionar cliente
- [ ] Adicionar produtos
- [ ] Configurar entrega
- [ ] Salvar pedido

### 2. Aprovação

- [ ] Verificar crédito do cliente
- [ ] Revisar valores
- [ ] Aprovar pedido
- [ ] Notificar estoque

### 3. Faturamento

- [ ] Verificar estoque disponível
- [ ] Gerar Nota Fiscal
- [ ] Enviar NF-e para o cliente
- [ ] Registrar no financeiro

### 4. Separação

- [ ] Imprimir separation list
- [ ] Separar itens
- [ ] Conferir volumes
- [ ] Registrar separação

### 5. Expedição

- [ ] Selecionar transportadora
- [ ] Gerar etiqueta
- [ ] Coletar volume
- [ ] Registrar envio

### 6. Entrega

- [ ] Rastrear entrega
- [ ] Confirmar recebimento
- [ ] Atualizar status
- [ ] Solicitar avaliação

## Detalhamento por Etapa

### Criação do Pedido

<Steps>

1. Acesse **Pedidos → Novo Pedido**
2. Busque e selecione o cliente
3. Adicione os produtos
4. Configure entrega e pagamento
5. Salve o pedido

</Steps>

### Aprovação

<Steps>

1. Acesse **Pedidos → Pendentes**
2. Clique no pedido
3. Revise os dados
4. Verifique o limite de crédito
5. Aprove ou rejeite

</Steps>

### Faturamento

<Steps>

1. Acesse **Pedidos → Aprovados**
2. Selecione o(s) pedido(s)
3. Clique em "Faturar"
4. Confirme os dados da NF
5. Gere a nota fiscal

</Steps>

### Separação

<Steps>

1. Acesse **Expedição → Aguardando**
2. Imprima a separação
3. Separe os itens no estoque
4. Confirme a separação
5. Conferência de volumes

</Steps>

### Expedição

<Steps>

1. Acesse **Expedição → Conferidos**
2. Selecione a transportadora
3. Gere a etiqueta
4. Aguarde coleta
5. Registre o envio

</Steps>

## Erros Comuns

| Erro | Etapa | Solução |
|------|-------|---------|
| Estoque insuficiente | Faturamento | Verificar estoque antes |
| NF-e rejeitada | Faturamento | Verificar dados da NF |
| Transportadora indisponível | Expedição | Escolher outra transportadora |
| Cliente não localizado | Entrega | Verificar endereço |

## Dicas

:::tip[Dica]
Processe os pedidos em lote para ganhar eficiência.
:::

:::tip[Dica]
Verifique o rastreamento diariamente para antecipar problemas.
:::

:::caution[Importante]
Sempre confirme os dados da NF-e antes de emitir. Uma NF-e cancelada gera trabalho extra.
:::
