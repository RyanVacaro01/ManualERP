Este guia apresenta o fluxo completo de compras a fornecedores.

## Etapas do Processo

### 1. Identificação da Necessidade

<Steps>

1. **Alerta automático**
   
   O sistema alerta quando estoque fica baixo.

2. **Solicitação manual**
   
   Funcionário solicita compra.

3. **Verificação**
   
   - Estoque atual
   - Pedidos pendentes
   - Necessidade real

</Steps>

### 2. Cotação com Fornecedores

<Steps>

1. **Criar cotação**
   
   - Acesse **Compras → Cotações**
   - Clique em "Nova Cotação"
   - Selecione os produtos

2. **Selecionar fornecedores**
   
   - Escolha 3 fornecedores (mínimo)
   - Envie solicitação

3. **Receber propostas**
   
   - Aguarde respostas
   - Compare preços e prazos

4. **Avaliar propostas**
   
   | Critério | Peso |
   |----------|------|
   | Preço | 40% |
   | Prazo | 30% |
   | Condição Pagamento | 20% |
   | Qualidade | 10% |

</Steps>

### 3. Aprovação da Compra

<Steps>

1. **Preparar aprovação**
   
   - Selecione a melhor cotação
   - Preencha dados complementares

2. **Enviar para aprovação**
   
   - Regras automáticas de aprovação
   - Aprovação manual (se necessário)

3. **Aprovar**
   
   - Revise dados
   - Aprove ou rejeite
   - Adicione observações

</Steps>

### 4. Pedido de Compra

<Steps>

1. **Gerar pedido**
   
   - Aprovação gera pedido automaticamente
   - Ou crie manualmente

2. **Enviar ao fornecedor**
   
   - E-mail automático
   - PDF do pedido
   - Confirmação

3. **Acompanhar**
   
   - Status do pedido
   - Previsão de entrega

</Steps>

### 5. Recebimento

<Steps>

1. **Conferir volumes**
   
   - Quantidade de volumes
   - Integridade das embalagens

2. **Conferir itens**
   
   - Quantidades
   - Qualidade
   - Nota fiscal

3. **Registrar divergências**
   
   - Itens faltantes
   - Itens avariados
   - Itens diferentes

4. **Confirmar recebimento**
   
   - Baixa automática no estoque
   - Atualização de custos

</Steps>

## Regras de Aprovação

| Valor | Aprovação |
|-------|-----------|
| Até R$ 2.000 | Automática |
| R$ 2.000 - R$ 10.000 | Gerente |
| R$ 10.000 - R$ 50.000 | Diretor |
| Acima de R$ 50.000 | Diretoria |
