Esta página lista os erros mais comuns e suas soluções.

## Erros de Login

### "Usuário ou senha incorretos"

**Causas:**
- Senha digitada incorretamente
- Caps Lock ativado
- Conta bloqueada após muitas tentativas

**Soluções:**
1. Verifique se Caps Lock está desativado
2. Digite a senha novamente com cuidado
3. Use "Esqueci minha senha" para redefinir
4. Se bloqueado, aguarde 15 minutos ou contate o TI

---

### "Conta bloqueada"

**Causas:**
- 5 tentativas incorretas de login

**Soluções:**
1. Aguarde 15 minutos para desbloqueio automático
2. Ou contate o administrador para desbloquear

---

### "Sessão expirada"

**Causas:**
- Inatividade por muito tempo

**Soluções:**
1. Faça login novamente
2. Use o sistema regularmente para evitar expiração

## Erros de Navegação

### "Página não encontrada" (404)

**Causas:**
- URL incorreta
- Página movida ou removida

**Soluções:**
1. Verifique a URL na barra de endereços
2. Use o menu de navegação
3. Use a busca para encontrar o conteúdo

---

### "Acesso negado" (403)

**Causas:**
- Sem permissão para acessar o módulo
- Perfil de usuário sem acesso

**Soluções:**
1. Verifique se você tem acesso ao módulo
2. Solicite acesso ao administrador
3. Use outro perfil de usuário (se disponível)

## Erros de Formulários

### "Campo obrigatório não preenchido"

**Causas:**
- Esqueceu de preencher um campo marcado com *

**Soluções:**
1. Preencha todos os campos obrigatórios
2. Campos obrigatórios estão marcados com asterisco (*)

---

### "CPF/CNPJ inválido"

**Causas:**
- Documento digitado incorretamente
- Documento não existe

**Soluções:**
1. Verifique os dígitos
2. Confirme com o cliente
3. Use o validador online

---

### "E-mail inválido"

**Causas:**
- Formato incorreto

**Soluções:**
1. Use o formato: usuario@dominio.com.br
2. Verifique se não há espaços
3. Confirme com o cliente

---

### "CEP não encontrado"

**Causas:**
- CEP inexistente
- CEP incorreto

**Soluções:**
1. Verifique o CEP no site dos Correios
2. Preencha o endereço manualmente

## Erros de Estoque

### "Estoque insuficiente"

**Causas:**
- Quantidade solicitada maior que disponível

**Soluções:**
1. Reduza a quantidade
2. Verifique se há estoque em trânsito
3. Solicite reposição ao estoquista

---

### "Produto sem estoque"

**Causas:**
- Produto esgotado

**Soluções:**
1. Verifique previsão de reposição
2. Ofereça produto similar
3. Registre pedido de compra

## Erros de NF-e

### "NF-e rejeitada pela SEFAZ"

**Causas:**
- Dados cadastrais incorretos
- NCM inválido
- CFOP incorreto
- Chave de acesso duplicada

**Soluções:**
1. Verifique os dados cadastrais
2. Confirme NCM e CFOP
3. Consulte o motivo da rejeição no portal
4. Corrija e reemita

---

### "Erro ao enviar NF-e"

**Causas:**
- Problema de conexão
- Certificado digital vencido
- Sistema fora do ar

**Soluções:**
1. Verifique sua conexão
2. Renove o certificado digital
3. Tente novamente mais tarde
4. Contate o suporte

## Erros de Integração

### "Marketplace não sincronizando"

**Causas:**
- Token expirado
- Credenciais inválidas
- API fora do ar

**Soluções:**
1. Verifique as credenciais
2. Renove o token
3. Consulte status da API
4. Contate o suporte

---

### "Pedido não importado"

**Causas:**
- Erro de mapeamento
- Dados incompletos
- Limite atingido

**Soluções:**
1. Verifique o log de importação
2. Confirme o mapeamento de produtos
3. Verifique limites da API
4. Importe manualmente

## Erros de Desempenho

### "Sistema lento"

**Causas:**
- Conexão lenta
- Navegador sobrecarregado
- Muitas abas abertas

**Soluções:**
1. Verifique sua conexão
2. Feche abas desnecessárias
3. Limpe o cache do navegador
4. Use Chrome ou Firefox atualizado

---

### "Página não carrega"

**Causas:**
- Conexão perdida
- Servidor fora do ar
- DNS não resolve

**Soluções:**
1. Verifique sua conexão
2. Acesse outro site para testar
3. Aguarde e tente novamente
4. Contate o TI

## Erros de Impressão

### "Não é possível imprimir"

**Causas:**
- Impressora desligada
- Driver desatualizado
- Permissão negada

**Soluções:**
1. Verifique se a impressora está ligada
2. Atualize o driver
3. Verifique as permissões
4. Use outro navegador

---

### "Danfe não imprime"

**Causas:**
- Plugin não instalado
- Navegador bloqueia pop-up

**Soluções:**
1. Instale o plugin necessário
2. Permita pop-ups para o domínio
3. Use Chrome ou Firefox

## Quando Contatar o Suporte

Contate o suporte quando:

- ✅ Você tentou as soluções acima
- ✅ O problema persiste
- ✅ Não encontra solução na documentação
- ✅ É um bug do sistema

### Informações para o Suporte

Ao abrir um chamado, informe:

1. **O que você estava fazendo**
2. **O que aconteceu**
3. **Mensagem de erro** (se houver)
4. **Print da tela** (se possível)
5. **Navegador e versão**
6. **Horário do problema**
