## Canais de Suporte

**suporte@seuaempresa.com.br**

- Horário: Segunda a sexta, 8h às 18h
- Retorno: Até 24 horas úteis
- Para: Dúvidas gerais, solicitações

---

### 📞 Telefone

**0800-123-4567**

- Horário: Segunda a sexta, 8h às 18h
- Para: Urgências, problemas críticos

---

### 💬 Chat

Disponível dentro do sistema:

1. Clique no ícone 💬 no canto inferior direito
2. Digite sua mensagem
3. Aguarde um atendente

**Horário:** Segunda a sexta, 8h às 18h

---

### 🎫 Chamado

Sistema de chamados integrado:

1. Acesse **Ajuda → Abrir Chamado**
2. Selecione a categoria
3. Descreva o problema
4. Anexe prints (se possível)
5. Envie

## Antes de Abrir um Chamado

### Verifique

- [ ] Consulte os [Erros Comuns](/troubleshoot/erros-comuns)
- [ ] Verifique o [FAQ](/troubleshoot/faq)
- [ ] Tente as soluções sugeridas
- [ ] Reinicie o navegador
- [ ] Limpe o cache

### Informações Necessárias

Ao abrir um chamado, tenha em mãos:

| Informação | Descrição |
|------------|-----------|
| **Módulo** | Onde está o problema |
| **Descrição** | O que aconteceu |
| **Passos** | Como reproduzir |
| **Print** | Captura de tela |
| **Erro** | Mensagem de erro |
| **Navegador** | Chrome, Firefox, etc. |
| **Horário** | Quando aconteceu |

## Categorias de Chamado

| Categoria | Descrição | Prioridade |
|-----------|-----------|------------|
| **Bug** | Erro no sistema | Alta |
| **Dúvida** | Como fazer algo | Normal |
| **Solicitação** | Nova funcionalidade | Normal |
| **Acesso** | Problemas de login | Alta |
| **Integração** | Marketplace, APIs | Alta |
| **Relatório** | Problemas com relatórios | Normal |

## Prioridades

| Prioridade | Tempo Resposta | Exemplo |
|------------|----------------|---------|
| **Crítica** | 1 hora | Sistema fora do ar |
| **Alta** | 4 horas | Módulo não funciona |
| **Normal** | 24 horas | Dúvida de uso |
| **Baixa** | 48 horas | Sugestão de melhoria |

## Acompanhar Chamado

### Pela Web

1. Acesse **Ajuda → Meus Chamados**
2. Veja o status
3. Adicione informações se necessário

### Por E-mail

Você recebe atualizações por e-mail quando:
- Chamado é aberto
- Chamado é respondido
- Chamado é resolvido

## Status do Chamado

| Status | Descrição |
|--------|-----------|
| **Aberto** | Chamado criado |
| **Em Andamento** | Equipe analisando |

| **Fechado** | Chamado encerrado |
