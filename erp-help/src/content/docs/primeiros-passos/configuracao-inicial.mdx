Ao acessar o sistema pela primeira vez, é importante realizar algumas configurações básicas para garantir uma experiência personalizada.

## Configurações do Perfil

<Steps>

1. **Acesse seu perfil**
   
   Clique no ícone do seu usuário no canto superior direito e selecione "Meu Perfil".

2. **Atualize seus dados**
   
   Preencha ou atualize:
   - Nome completo
   - E-mail de contato
   - Telefone
   - Departamento

3. **Configure notificações**
   
   Escolha como deseja receber notificações:
   - E-mail
   - Alertas no sistema
   - Push no navegador

4. **Defina preferências**
   
   - Idioma do sistema
   - Fuso horário
   - Formato de data e moeda

</Steps>

## Configurações de Segurança

### Alterar Senha

:::caution[Importante]
Altere sua senha temporária imediatamente após o primeiro login!
:::

1. Acesse **Perfil → Segurança**
2. Clique em **Alterar Senha**
3. Insira a senha atual
4. Digite a nova senha (mínimo 8 caracteres)
5. Confirme a nova senha
6. Clique em **Salvar**

### Autenticação em Duas Etapas (2FA)

Recomendamos ativar a autenticação em duas etapas:

1. Acesse **Perfil → Segurança**
2. Clique em **Ativar 2FA**
3. Escaneie o QR Code com seu app de autenticação
4. Insira o código gerado
5. Salve os códigos de backup em local seguro

### Sessões Ativas

Visualize e encerre sessões em outros dispositivos:

1. Acesse **Perfil → Segurança → Sessões**
2. Revise as sessões ativas
3. Encerre sessões desconhecidas

## Configurações de Exibição

### Tema

Escolha entre:
- ☀️ Claro (padrão)
- 🌙 Escuro
- 🔄 Automático (baseado no sistema)

### Layout

- **Compacto** - Mais informações na tela
- **Confortável** - Mais espaço entre elementos
- **Padrão** - Equilíbrio entre os dois

### Colunas da Tabela

Personalize quais colunas aparecem nas listagens:

1. Clique no ícone ⚙️ no cabeçalho da tabela
2. Marque ou desmarque as colunas
3. Arraste para reordenar
4. Salve a visualização

## Dicas Iniciais

:::tip[Dica]
Configure seu painel personalizado adicionando os widgets mais usados:
1. Clique em "Personalizar" no painel
2. Arraste os widgets desejados
3. Redimensione conforme necessário
4. Salve o layout
:::
