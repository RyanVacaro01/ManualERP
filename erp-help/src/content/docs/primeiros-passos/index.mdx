Bem-vindo ao sistema ERP! Este guia vai ajudá-lo a começar a usar o sistema de forma rápida e eficiente.

## O que você vai aprender

- Como acessar o sistema
- Configurações iniciais importantes
- Navegação básica
- Primeiras ações no sistema

## Pré-requisitos

Antes de começar, certifique-se de ter:

- Acesso ao sistema (usuário e senha)
- Navegador web atualizado (Chrome ou Firefox recomendados)
- Conexão estável com a internet

<Steps>

1. **Acesse o sistema**
   
   Abra o navegador e acesse a URL fornecida pela sua empresa.
   
   Exemplo: `https://erp.suaempresa.com.br`

2. **Faça login**
   
   Insira seu usuário e senha na tela de login.
   
   :::note[Primeiro acesso]
   Se este é seu primeiro acesso, use a senha temporária enviada por e-mail.
   :::

3. **Complete o cadastro**
   
   Ao entrar pela primeira vez, o sistema solicitará:
   - Alteração de senha
   - Dados pessoais
   - Preferências de notificação

4. **Explore o painel**
   
   O painel principal mostra:
   - Resumo das atividades
   - Acesso rápido aos módulos
   - Notificações pendentes

</Steps>

## Navegação Básica

### Menu Lateral
O menu lateral contém todos os módulos do sistema. Clique em cada item para acessar.

### Barra Superior
Na barra superior você encontra:
- **Busca global** - Encontre qualquer coisa rapidamente
- **Notificações** - Alertas e avisos
- **Perfil** - Acesse suas configurações
- **Sair** - Encerre sua sessão

### Atalhos de Teclado
O sistema possui vários atalhos para agilizar sua navegação:

| Atalho | Ação |
|--------|------|
| `Ctrl + K` | Busca global |
| `Ctrl + S` | Salvar |
| `Ctrl + N` | Novo registro |
| `Esc` | Fechar modal |
| `?` | Ajuda |

:::tip[Dica]
Pressione `?` em qualquer lugar do sistema para ver todos os atalhos disponíveis.
:::
