Este guia apresenta como emitir Notas Fiscais Eletrônicas (NF-e) pelo sistema.

## O que é NF-e

A Nota Fiscal Eletrônica (NF-e) é um documento fiscal emitido eletronicamente para registrar operações comerciais com mercadorias.

## Pré-requisitos

- ✅ Certificado digital válido (e-CNPJ)
- ✅ Inscrição Estadual ativa
- ✅ Cadastro na SEFAZ
- ✅ Configuração fiscal no sistema

## Configuração Inicial

<Steps>

1. **Acesse as configurações**
   
   - Clique em **Extras → Configurações**
   - Vá em **Fiscal → NF-e**

2. **Insira dados da empresa**
   
   - Razão Social
   - CNPJ
   - Inscrição Estadual
   - Endereço
   - Telefone

3. **Configure o certificado digital**
   
   - Tipo: A1 ou A3
   - Upload do arquivo (A1)
   - Senha do certificado

4. **Configure a SEFAZ**
   
   - UF de emissão
   - Ambiente: Produção ou Homologação
   - Numberação inicial

5. **Teste a conexão**
   
   - Clique em "Testar Conexão com SEFAZ"
   - Verifique se retorna sucesso

</Steps>

## Emitir NF-e

### A partir de um Pedido

<Steps>

1. **Acesse o pedido**
   
   - Acesse **Pedidos → Aprovados**
   - Selecione o pedido

2. **Clique em "Faturar"**
   
   - O sistema abre o formulário de NF-e

3. **Confirme os dados**
   
   - Dados do destinatário
   - Itens da nota
   - Valores
   - Impostos

4. **Configure a entrega**
   
   - Frete: Por conta de (Emitente/Destinatário)
   - Transportadora
   - Peso e volumes

5. **Revise a NF-e**
   
   - Verifique todos os campos
   - Confira os valores
   - Valide os impostos

6. **Emita a NF-e**
   
   - Clique em "Emitir NF-e"
   - Aguarde a autorização da SEFAZ

7. **Baixe o DANFE**
   
   - Após autorização, baixe o DANFE em PDF
   - Envie ao cliente

</Steps>

## Dados da NF-e

### Dados do Emitente

| Campo | Descrição |
|-------|-----------|
| Razão Social | Nome da empresa |
| CNPJ | Documento da empresa |
| Inscrição Estadual | IE |
| Endereço | Endereço completo |

### Dados do Destinatário

| Campo | Descrição |
|-------|-----------|
| Nome/Razão Social | Nome do cliente |
| CPF/CNPJ | Documento |
| Endereço | Endereço de entrega |
| IE | Inscrição Estadual (PJ) |

### Produtos

| Campo | Descrição |
|-------|-----------|
| Código | SKU do produto |
| Descrição | Nome do produto |
| NCM | Nomenclatura Comum |
| CFOP | Código da operação |
| Unidade | kg, un, lt, etc. |
| Quantidade | Qtd vendida |
| Valor Unitário | Preço de venda |
| Valor Total | Qtd × Preço |

### Impostos

| Imposto | Descrição |
|---------|-----------|
| ICMS | Imposto estadual |
| IPI | Imposto sobre industrialização |
| PIS | Programa de integração |
| COFINS | Contribuição para o FINUS |

## CFOPs Comuns

| CFOP | Operação |
|------|----------|
| 5.102 | Venda dentro do estado |
| 6.102 | Venda para outro estado |
| 1.102 | Compra dentro do estado |
| 2.102 | Compra de outro estado |
| 5.405 | Venda de produto com ST |
| 6.405 | Venda de produto com ST interestadual |

## Status da NF-e

| Status | Descrição |
|--------|-----------|
| **Rascunho** | Em criação |
| **Autorizada** | Autorizada pela SEFAZ |
| **Enviada** | Enviada ao destinatário |
| **Cancelada** | Nota cancelada |
| **Inutilizada** | Número inutilizado |

## Cancelamento

### Quando Cancelar

- Erro nos dados
- Desistência do cliente
- Operação não concretizada

### Como Cancelar

<Steps>

1. **Acesse a NF-e**
   
   - Acesse **Fiscal → NF-e**
   - Selecione a nota

2. **Clique em "Cancelar"**
   
   - Informe o motivo
   - Confirme o cancelamento

3. **Envie o cancelamento**
   
   - O sistema envia à SEFAZ
   - Aguarde confirmação

4. **Comunique ao cliente**
   
   - Envie e-mail informando
   - Anote o protocolo

</Steps>

## Correção

### Carta de Correção

Para corrigir dados não fiscais:

1. Acesse a NF-e
2. Clique em "Carta de Correção"
3. Informe a correção
4. Envie à SEFAZ

## Erros Comuns

| Erro | Causa | Solução |
|------|-------|---------|
| Certificado vencido | Validade encerrada | Renovar certificado |
| NCM inválido | Código incorreto | Verificar NCM |
| CFOP incorreto | Operação errada | Verificar CFOP |
| Dados cadastrais | Informações erradas | Atualizar dados |
| SEFAZ offline | Sistema indisponível | Aguardar |

## Dicas

:::tip[Dica]
Emita a NF-e imediatamente após faturar o pedido para evitar atrasos.
:::

:::tip[Dica]
Mantenha o certificado digital atualizado para evitar problemas na emissão.
:::

:::caution[Importante]
Nunca cancele uma NF-e sem motivo justificado. Isso gera registro na SEFAZ.
:::
