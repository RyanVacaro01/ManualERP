## Pré-requisitos

- ✅ Conta ativa no marketplace
- ✅ Acesso ao módulo de Marketplace
- ✅ Chaves de API do marketplace
- ✅ Produtos cadastrados no ERP

## Configurar Mercado Livre

<Steps>

1. **Obter credenciais**
   
   - Acesse o Mercado Livre
   - Vá em **Mercado Pago → Credenciais**
   - Copie o **App ID** e **Secret Key**

2. **Acesse o ERP**
   
   - Clique em **Marketplace**
   - Selecione **Mercado Livre**

3. **Insira as credenciais**
   
   - App ID
   - Secret Key
   - Token de acesso

4. **Autorize a integração**
   
   - Clique em "Conectar"
   - Autorize no Mercado Livre

5. **Configure a sincronização**
   
   - Mapeamento de categorias
   - Sincronização de preços
   - Sincronização de estoque

6. **Teste a conexão**
   
   - Clique em "Testar"
   - Verifique se retorna dados

7. **Ative a integração**
   
   - Clique em "Ativar"

</Steps>

## Configurar Shopee

<Steps>

1. **Obter credenciais**
   
   - Acesse o Shopee Seller Center
   - Vá em **Settings → API**
   - Copie o **Partner ID** e **Secret Key**

2. **Acesse o ERP**
   
   - Clique em **Marketplace**
   - Selecione **Shopee**

3. **Insira as credenciais**
   
   - Partner ID
   - Secret Key

4. **Configure a loja**
   
   - Selecione a loja
   - Configure as preferências

5. **Ative a integração**

</Steps>

## Configurar Amazon

<Steps>

1. **Obter credenciais**
   
   - Acesse o Amazon Seller Central
   - Vá em **Settings → User Permissions**
   - Crie uma credencial de API
   - Copie **Access Key** e **Secret Key**

2. **Acesse o ERP**
   
   - Clique em **Marketplace**
   - Selecione **Amazon**

3. **Insira as credenciais**
   
   - Access Key
   - Secret Key
   - Seller ID
   - Marketplace ID

4. **Configure a sincronização**
   
   - Mapeamento de categorias Amazon
   - Regras de preço
   - Gestão de estoque

5. **Ative a integração**

</Steps>

## Mapeamento de Dados

### Produtos → Anúncios

| Campo ERP | Campo Marketplace |
|-----------|-------------------|
| SKU | ID do anúncio |
| Nome | Título |
| Descrição | Descrição |
| Preço | Preço de venda |
| Estoque | Quantidade |
| Imagens | Fotos |

### Categorias

| Categoria ERP | Marketplace |
|---------------|-------------|
| Roupas | Moda |
| Calçados | Calçados |
| Acessórios | Acessórios |

## Sincronização

### Frequência

| Dados | Frequência |
|-------|------------|
| Produtos | A cada 15 min |
| Estoque | A cada 5 min |
| Preços | A cada 15 min |
| Pedidos | A cada 10 min |
| Status | A cada 15 min |

### O que é Sincronizado

**ERP → Marketplace:**
- Cadastro de produtos
- Preços
- Estoque
- Imagens

**Marketplace → ERP:**
- Pedidos recebidos
- Pagamentos
- Status de envio
- Devoluções

## Configurações Avançadas

### Regras de Preço

| Regra | Descrição |
|-------|-----------|
| Fixo | Preço igual ao ERP |
| Markup | Percentual acima |
| Promocional | Regra para promoções |

### Regras de Estoque

| Regra | Descrição |
|-------|-----------|
| Sincronizar tudo | Envia todo estoque |
| Estoque mínimo | Só acima do mínimo |
| Reserva | Mantém reserva no ERP |

### Ativar/Desativar

| Regra | Descrição |
|-------|-----------|
| Automático | Novos produtos vão pro marketplace |
| Manual | Só os que você selecionar |
| Desativar sem estoque | Desativa quando zera |

## Erros Comuns

| Erro | Causa | Solução |
|------|-------|---------|
| Token expirado | Validade encerrada | Renovar token |
| Credenciais inválidas | Dados incorretos | Verificar chaves |
| API indisponível | Marketplace fora | Aguardar |
| Limite atingido | Muitas requisições | Reduzir frequência |

## Dicas
